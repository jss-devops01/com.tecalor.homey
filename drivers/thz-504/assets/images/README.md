# Device Images

This directory should contain the following PNG images for the THZ-504 device:

- `small.png` - 75x75 pixels
- `large.png` - 300x300 pixels  
- `xlarge.png` - 500x500 pixels

Currently, placeholder 1x1 pixel PNG files are used for development.
Replace these with actual device images before publishing to the Homey App Store.

## Recommended Images

- Product photos of the Tecalor THZ-504 heat pump
- Clean, professional product shots with transparent or white backgrounds
- High resolution images that show the device clearly
- Consistent styling across all three sizes
